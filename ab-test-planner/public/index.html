A/B Test Planner

Plan the test before you run it.

Give the planner your conversion baseline, traffic, expected change, and metrics. It calculates a sample-size estimate and whole-week duration, then checks the experiment plan you write.

What it helps you prepare

A hypothesis, one primary metric, guardrails, event names and properties, pre-launch checks, and a no-peeking stop rule.

Clear limits

It works only with the details you provide. It does not connect to analytics, change a website, run an experiment, or promise an outcome.
