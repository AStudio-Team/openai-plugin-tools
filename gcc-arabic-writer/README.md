# GCC Arabic Writer

A portable skills-only OpenAI plugin for native Arabic advertising, luxury, social and business copy across the six GCC markets.

## Package shape

- `plugin.json`: portable Agent Plugins manifest.
- `skills/gcc-arabic-writer/SKILL.md`: self-contained public writing workflow.
- `assets/`: listing assets for local testing and later submission.

The distributable package contains only public product instructions and listing assets. It contains no client data, private corpus, local path, credential, internal identifier or operational system reference.

## External gates

Developer identity verification, public upload, review, submission and publication require fresh approval.
