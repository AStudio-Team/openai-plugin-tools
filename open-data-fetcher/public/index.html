Green

Export permitted

An explicit open license permits redistribution. Attribution remains attached.

Amber

Publisher first

Unknown or conditional rights open the official publisher page by default. Server export stays disabled.

Red

Export blocked

Restricted or conflicting rights block server preview and export.

Human-controlled by design

  1. Submit a search to an approved source.
  2. Choose one dataset yourself.
  3. Review license, attribution and estimated size.
  4. Inspect a bounded sample.
  5. Choose columns, filters, row limit and format.
  6. Review and confirm the temporary download.

No arbitrary URLs, credentials, browser automation or local dependencies.
