Support

Contact support@astudio.agency.

Include

  • The official source name
  • The dataset title and opaque reference
  • The visible error category
  • Whether the failure happened during search, inspection, preview or export

Do not include

Do not email API keys, cookies, passwords, signed links, private data, exported rows or confidential files.

Common outcomes

  • Amber rights: review and download from the official publisher page.
  • Red rights: server export is intentionally blocked.
  • Resource unavailable: the file host may be outside the reviewed adapter allowlist.
  • Preview failed: no export is created. Use the official publisher page.
  • Download expired: repeat the final export confirmation to create a new temporary artifact.
