Grounded Citations support

Include the visible error code, the tool name, and whether the source was a URL, PDF, DOCX, text, or HTML. Do not include the source content itself.

Common issues

  • Source rejected: only public HTTPS destinations and supported file types are accepted.
  • Quote not found: use exact source wording with at least three words. The matcher does not paraphrase or alter numbers.
  • Revision conflict: refresh the ledger preview and use the current revision.
  • Session unavailable: the session was deleted or expired after its idle or hard limit.

Security reports

Do not test private networks or submit secrets. Describe the issue without including temporary URLs, session tokens, source text, or personal information.
