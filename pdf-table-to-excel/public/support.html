Plugin support

How can we help?

For a technical problem, include the plugin name, what you asked it to do, the error shown and whether the PDF contained selectable text. Never send passwords, API keys or confidential documents.

Common PDF issues

  • No tables found: the PDF may be a scan. OCR is not included in this release.
  • File rejected: confirm it is a PDF smaller than 20 MB and no more than 200 pages.
  • Download expired: run the conversion again. Output links expire after 15 minutes.

Arabic writing feedback

Name the target country, format and intended tone. For localization feedback, quote only the specific line that needs correction and explain the audience.

Diagram support

Include the diagram type, failed stage and validation message. Do not send confidential diagram content. The app does not upload files or create public share links.
